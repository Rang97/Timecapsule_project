# 8Bit - TIMECAPSULE

`8Bit - TIMECAPSULE`은 사용자가 미래의 특정 날짜에 열어볼 수 있는 타임캡슐을 작성하고 보관할 수 있는 레트로 스타일의 웹 애플리케이션입니다. 사용자는 제목, 내용, 개봉일을 입력해 타임캡슐을 저장할 수 있으며, 개봉일이 지난 타임캡슐만 내용을 확인할 수 있습니다.

## 주요 기능

- **타임캡슐 작성**: 제목, 내용, 개봉일을 입력해 저장합니다.
- **개봉일 설정**: 미래의 원하는 날짜를 개봉일로 지정합니다.
- **열람 제한**: 개봉일 이전에는 타임캡슐의 내용을 볼 수 없습니다.
- **모달 열람**: 개봉일이 지난 타임캡슐은 클릭하면 모달 창에서 내용을 확인합니다.
- **인증/로그아웃**: Spring Security 기반 로그인과 로그아웃을 지원합니다.
- **사용자 정보 출력**: Thymeleaf로 로그인한 사용자의 정보를 화면에 표시합니다.

## 화면 구성

### 1. 타임캡슐 작성 영역

사용자는 다음 정보를 입력하여 타임캡슐을 저장할 수 있습니다.

| 입력 항목 | 설명 |
| 제목 | 타임캡슐의 제목 |
| 내용 | 미래에 열어볼 내용 |
| 개봉일 | 열람이 가능해지는 날짜 |

작성 후 `보관하기` 버튼을 누르면 데이터가 저장됩니다.

### 2. 타임캡슐 리스트

저장된 타임캡슐 목록이 표시되며, 개봉일 기준으로 상태가 달라집니다.

- 개봉일이 지난 타임캡슐
    - 클릭 가능
    - `"타임캡슐을 열어보세요."` 문구 표시
    - 클릭 시 모달 창에서 내용 확인 및 삭제 가능

- 개봉일이 지나지 않은 타임캡슐
    - 클릭 불가
    - `"개봉날을 기대해주세요."` 문구 표시

### 3. 타임캡슐 모달

개봉 가능한 타임캡슐을 클릭하면 모달 창이 열리고 **제목 / 개봉일 / 내용**이 표시됩니다.

## 실행 흐름

1. 사용자가 로그인합니다.
2. 메인 화면에서 사용자 이름과 타임캡슐 작성 폼이 표시됩니다.
3. 페이지 로딩 시 사용자의 타임캡슐 목록을 자동으로 조회합니다.
4. 사용자는 제목, 내용, 개봉일을 입력해 타임캡슐을 저장합니다.
5. 저장된 타임캡슐은 목록에 표시됩니다.
6. 개봉일이 지난 타임캡슐은 클릭하여 내용을 확인할 수 있습니다.
7. 개봉일이 지나지 않은 타임캡슐은 내용을 확인할 수 없습니다.
